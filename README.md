# «Справа про порожній мольберт: Голос Надії»
### Шкільний інтерактивний детективний квест до акції «16 днів проти насильства» (5–9 класи)

Готовий до публікації на **GitHub Pages** статичний веб-додаток (HTML5, CSS3, Vanilla JS) для проведення гібридного шкільного квесту про протидію булінгу, газлайтингу, маніпуляціям та захист особистих і цифрових кордонів.

---

## 🎨 Особливості та архітектура
1. **100% автономний клієнтський стек:** Чистий HTML5, CSS3, Vanilla JS без сторонніх бібліотек чи фреймворків.
2. **Mobile-First дизайн (480px десктопний контейнер):** Стилізований під підлітковий месенджер із вкладкою «Дошка розслідування» (досьє, динаміка стосунків, архів голосових записів).
3. **100% векторна графіка в коді (SVG):** Унікальні авторські аватари для 5 персонажів (Надія, Софія, Максим, Денис, Лєра) та анімований звуковий плеєр.
4. **Аудіоплеєр з graceful fallback:**
   - Працює як з файлами `assets/audio/voice_nadiia_1.mp3` .. `voice_nadiia_4.mp3` та фоновою музикою `assets/audio/bg_detective_theme.mp3`, так і у беззвучному режимі чи при блокуванні автоплею браузером (анімована хвиля + розгортання повної текстової розшифровки).
5. **Автозбереження прогресу:** Стан гри автоматично записується в `localStorage`.

### Підтримка URL-параметрів для QR-кодів:
- `?team=1` ... `?team=6`: активація команди без скидання вже пройдених кроків при повторному скануванні.
- `?unlock=XXXX`: автоматичне зчитування коду локації зовнішньою камерою смартфона.
- Вбудована цифрова клавіатура (NumPad) для ручного введення 4-значного коду.

## 🚀 Публікація на GitHub Pages
1. Завантажте репозиторій на GitHub.
2. Перейдіть у **Settings ➔ Pages**.
3. У розділі **Build and deployment** оберіть **Source: Deploy from a branch** -> гілка `main` (або `master`), папка `/ (root)`.
4. Збережіть. За кілька секунд додаток буде доступний за адресою `https://<ваш-юзернейм>.github.io/<назва-репозиторію>/`.
