# «Справа про порожній мольберт: Голос Надії»
### Шкільний інтерактивний детективний квест до акції «16 днів проти насильства» (5–9 класи)

Готовий до публікації на **GitHub Pages** статичний веб-додаток (HTML5, CSS3, Vanilla JS) для проведення гібридного шкільного квесту про протидію булінгу, газлайтингу, маніпуляціям та захист особистих і цифрових кордонів.

---

## 🎨 Особливості та архітектура
1. **100% автономний клієнтський стек:** Чистий HTML5, CSS3, Vanilla JS без сторонніх бібліотек чи фреймворків.
2. **Mobile-First дизайн (480px десктопний контейнер):** Стилізований під підлітковий месенджер із вкладкою «Дошка розслідування» (досьє, динаміка стосунків, архів голосових записів).
3. **100% векторна графіка в коді (SVG):** Унікальні авторські аватари для 5 персонажів (Надія, Софія, Максим, Денис, Лєра) та анімований звуковий плеєр.
4. **Детективний аудіо-дует (Хронікер та Надія) з Audio Ducking та Graceful Fallback:**
   - **Хронікер розслідування (Євгеній Шевченко, дорослий чоловічий голос):** офіційний голос хроніки — вступний брифінг, аудіопротоколи станцій 1..6, пауза на урок, запрошення до Штабу та фінальний вердикт.
   - **Головна героїня Надія Кравчук (юний жіночий голос):** вступне звернення у блокноті, 6 особистих спогадів під кожну локацію, 4 чернетки в живому чаті та фінальна промова подяки.
   - **Audio Ducking:** під час звучання будь-якого голосу фонова музика (`bg_detective_theme.mp3`) автоматично й плавно приглушується до 12%, а після завершення повертається до 35%.
   - **Правило одного голосу:** у будь-який момент часу відтворюється лише один голос; запуск нового запису миттєво зупиняє попередній.
   - **Стартова заставка та User Gesture:** кнопка «Розпочати розслідування» легалізує автоплей аудіо в сучасних мобільних браузерах.
   - **Надійний Fallback:** при відсутності аудіофайлу чи беззвучному режимі плеєр симулює анімацію хвилі та розгортає повну текстову розшифровку.
5. **Автозбереження прогресу:** Стан гри автоматично записується в `localStorage`.

### Підтримка URL-параметрів та сканування QR-кодів:
- `?team=1` ... `?team=6`: прив'язка телефону до команди (без скидання пройдених кроків при повторному скануванні).
- `?unlock=XXXX`: автоматичне зчитування коду локації зовнішньою камерою смартфона або вбудованим сканером.
- **Вбудований сканер QR-коду:** кнопка `Сканувати QR` у закріпленій нижній панелі.
- **Оптимізація камери та енергозбереження:** апаратна камера пристрою активується виключно в момент відкриття вікна сканера та миттєво повністю вимикається (індикатор камери згасає, треки зупиняються) одразу після зчитування коду або закриття вікна користувачем.
- Вбудована цифрова клавіатура (NumPad) для альтернативного ручного введення 4-значного коду.
- **Динамічна таємниця слідства:** на дошці розслідування та в архіві аудіо відображаються лише розкриті станції та фактично розблоковані записи Надії; невідвідані локації заблюрені зі штампом `[ЗАСЕКРЕЧЕНО]` для запобігання спойлерам.
- **Локальні налаштування:** прив'язка пристрою до команди через QR та миттєве скидання прогресу на поточному телефоні без введення паролів.

## 🚀 Публікація на GitHub Pages
1. Завантажте репозиторій на GitHub.
2. Перейдіть у **Settings ➔ Pages**.
3. У розділі **Build and deployment** оберіть **Source: Deploy from a branch** -> гілка `main` (або `master`), папка `/ (root)`.
4. Збережіть. За кілька секунд додаток буде доступний за адресою `https://<ваш-юзернейм>.github.io/<назва-репозиторію>/`.
