# Каталог сюжетних зображень квесту «Справа про порожній мольберт»

Ця директорія підготовлена для розміщення згенерованих ілюстрацій до сюжетних епізодів у чаті розслідування.

## 📁 Структура папок та файлів:

### 1. `assets/images/episodes/` (Сюжетні моменти та докази)
- `easel_empty.jpg` — Епізод 0: Порожній дерев'яний мольберт у шкільному фойє, розкидані фарби, відчуття раптового зникнення робіт.
- `notebook_notes.jpg` — Епізод 0: Відкритий робочий блокнот Надії на широкому шкільному підвіконні з ескізами та голосовими позначками.

### 2. `assets/images/clues/` (Локації вчителів та станції квесту)
- `station_1_inf.jpg` — Станція 1: Комп’ютерний клас (монітори з чатом, відкритий мем про Надію, кабінет інформатики).
- `station_2_math.jpg` — Станція 2: Кабінет математики (дошка з формулами, графік чергувань виставки, перекладання роботи).
- `station_3_science.jpg` — Станція 3: Лабораторія фізики та хімії (штативи, мензурки, плакат про взаємоповагу, атмосфера сарказму).
- `station_4_lit.jpg` — Станція 4: Кабінет літератури (книжкові шафи, цитати про людяність, порожній стілець Надії).
- `station_5_history.jpg` — Станція 5: Кабінет історії (історичні карти, виставка гідності, авторитетний тиск).
- `station_6_bio.jpg` — Станція 6: Кабінет біології (мікроскопи, плакати екосистеми класу, знецінення почуттів).

### 3. `assets/images/charter/` (Фінал та примирення)
- `hq_psychologist.jpg` — Фінальна локація (Код 1616): Кабінет шкільного психолога / Штаб Примирення (м'які крісла, затишок, безпечний простір).
- `reconciliation_complete.jpg` — Фінал розслідування: Повернення Надії в оргкомітет, спільна виставка малюнків з підписами всієї команди.

## 📐 Рекомендації до генерації зображень:
- **Формат:** JPG або WebP.
- **Співвідношення сторін:** 16:9 (наприклад, `1280x720` або `960x540`) або 4:3 (`1024x768`).
- **Стиль:** Реалістичний шкільний детектив, тепла кінематографічна палітра, без наукової фантастики.
- **Оптимізація:** До 250–350 КБ на одне зображення для миттєвого завантаження на смартфонах.

> [!NOTE]
> Веб-додаток має вбудовану технологію **Graceful Fallback**: якщо файл зображення ще не додано в папку, блок зображення автоматично залишається невидимим і не створює порожніх рамок чи помилок у чаті. Як тільки файл з'являється у відповідній папці — він миттєво відображається в чаті з можливістю відкриття на весь екран у лайтбоксі!
